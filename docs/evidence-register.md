# Project evidence register

The identifiers E1–E9 match Appendix A of the dissertation. These are project experiment records. Published literature is cited separately in the dissertation bibliography.

Every link below resolves to a retained record. The machine-readable [register](../results/evidence/register.json) lists all 218 records across these groups; [manifest.json](../results/evidence/manifest.json) records their sizes, original paths and SHA-256 hashes. The records retain their original wording and experiment chronology. A historical plan or result is evidence for that stage, not a description of the current selected system.

For the final scores, start with [results/final/final_results.json](../results/final/final_results.json). See [REPRODUCE.md](../REPRODUCE.md) for verification commands and the data and model artifacts required for a full rerun.
