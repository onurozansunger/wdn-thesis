# Thesis review evidence — 14 September 2026

Companion to the revised thesis and Appendix A. 223 byte-identical project records with original paths, sizes and SHA-256 hashes in `manifest.json`.

Run `python3 verify.py` to check every record hash, the original thirty-pair replay confirmation, all supplementary single-classifier confusion counts/means/thresholds, and the historical zero-versus-three-hour comparison.

The supplement includes the new baseline's frozen protocol, complete per-source results and per-model settings. Both information allowances and both calibration objectives are retained. Baseline evaluations reuse six sources per network after the final hybrid results were known; they are not a fresh independent confirmation. The historical latency comparison belongs to the earlier Modena configuration, not the final ten-seed systems.

This is an inspection supplement, not a full prediction-reproduction environment. Large data arrays, prediction arrays and fitted model binaries remain in the project archive. The supplied hashes record their identities. A public archival deposit has not been made.
